# 美的集团（000333.SZ）2025 年年报财务报表分析 —— Python 程序包

本项目用 Python 对**美的集团（000333.SZ）2025 年年度报告**的三张主表
（资产负债表、利润表、现金流量表）完成：

1. **项目结构分析**（共同比分析 / 垂直分析）
2. **项目趋势分析**（定基指数 + 环比增长率 + CAGR）
3. **财务指标分析**（偿债 / 营运 / 盈利 / 发展 / 现金质量，共 40 项）
4. **杜邦分析**（三因素 + 五因素 + 连环替代法归因）

分析区间 2021–2025 年；趋势与指标采用 5 年数据，
杜邦与指标使用**平均余额**口径（因此额外采集了 2021 年期末数）。

## 二、安装与运行

```bash
# 1. 安装依赖（建议使用虚拟环境）
pip install -r requirements.txt

# 2. 采集数据（需要可访问东方财富与新浪财经）
python fetch_data.py

# 3. 运行分析（生成全部表格、图表、Excel 汇总、关键结论 JSON）
python run_all.py

# 4. 生成 HTML 报告
python build_report.py
```

常用参数：

```bash
python run_all.py --no-charts          # 只出数据表，跳过图表
python run_all.py --years 2023 2024 2025
python build_report.py -o 自定义路径.html
```

## 三、数据来源与口径

| 项目 | 说明 |
| --- | --- |
| 主数据源 | 东方财富 F10 财务分析接口（`RPT_F10_FINANCE_G*`），标准化科目字段，单位 **元** |
| 核对数据源 | 新浪财经财务报表页面（`vFD_*`），单位 **万元**，用于逐科目交叉核验 |
| 报表口径 | 中国企业会计准则（CAS）**合并报表**，与公司 A 股年度报告一致 |
| 分析期间 | 2021–2025 年（趋势定基年 2021 = 100） |
| 平均余额 | （上年年末余额 + 本年年末余额）/ 2 |

**数据质量控制**（见 `analysis/verify.py`，结果在 `output/tables/00_*.csv`）：

1. 会计恒等式校验 7 项全部通过（资产 = 负债 + 权益、净利润 = 归母 + 少数股东损益等）；
2. 双数据源交叉核验 140 个科目-年度组合，133 个完全一致，
   7 个差异项均已定位原因（2023 年成本/销售费用重分类、新浪模板科目错位等）。

## 四、关键口径约定

- 周转率、ROA、ROE 的分母一律使用**平均余额**；
- 周转率与利润率以**营业收入**为分子（而非营业总收入），
  因此「销售净利率 × 总资产周转率 = ROA」严格成立，杜邦分解无残差；
- 利息费用取自东方财富字段 `FE_INTEREST_EXPENSE`
  （`INTEREST_EXPENSE` 字段为空值，不可用）；
- 每股指标的分母使用期末股本（实收资本，面值 1 元）。

## 六、更换分析对象

修改 `config.py` 中的 `COMPANY`（证券代码与新浪代码）即可复用整套流程，
科目映射 `COLUMNS` 已按证监会报表格式标准化，适用于 A 股一般工业与
消费类公司；金融、地产等特殊行业需补充相应科目。
