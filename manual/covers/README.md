# 章首封面图 · 手动插入说明

## 尺寸与位置

图片是 1024×1365（3:4 竖幅）。手册正文可用宽度 164 mm。

- **推荐宽度 92–100 mm**，居中，高度约 123–133 mm，放在章标题**之后**、Abstract 框之前。
  这样一页能容纳「章标题 + 图 + Abstract」，不会把 Abstract 挤到下一页。
- 想更接近 Hello 算法的整页冲击力，可用 **120 mm 宽**（高 160 mm），但那一页就只放得下图和标题，Abstract 会移到下一页 —— 原书正是这么排的（标题与图独占一页，Abstract 在图内下方）。

在 Word 里：`插入 → 图片 → 此设备`，右键图片 →「大小和属性」→ 高度锁定比例，取消「与文字匹配」，环绕方式选「上下型」。

## 标题压不压进图里？

**这一张（项目一）不要压字。** 实测全高干净度剖面：最好的位置是图高 88%–99%（标准差 30.5），其余各处标准差 36–48，都太杂，白字会糊。

原因：生成这张时没有约束"主体下压、上方留深色天空"，所以齿轮铺满了整个画面。

处理方式二选一：

1. **标题留在图外**（推荐）：沿用手册现有的章标题样式，图放在标题下方。视觉依然成立。
2. **一定要压字**：在 Word 里于图上叠一个「矩形」，填充黑色、透明度 25–30%，无边框，压在图高 80%–97% 处，再把白色标题文本框放在其上。

## 后续四张（项目二—五）

提示词已统一加上硬约束：

> 所有主体元素集中在画面下方三分之二，画面上方三分之一是深邃的暗色天空与薄雾，几乎不含细节，作为后期叠加白色标题的安静区域。

所以那四张生成后**可以直接在上方三分之一压白字**，无需蒙版。生成前建议仍按上面的剖面方法复验一次（脚本逻辑：滑窗取 720×150 居中带，亮度 ≤100 且标准差 <28 即为干净带）。
