Quick Start

快速开始

01 / 03 / 05 三个项目以 Git 子模块引入，克隆后务必执行第三行；02 / 04 的代码直接在本仓库中。

# 1. 克隆（GitHub，或换用文末 Gitee 镜像）
git clone git@github.com:yohoten/pyfin_cookbook.git
cd pyfin_cookbook
# 2. 拉取子模块：项目 01 / 03 / 05（缺了这步三个目录是空的）
git submodule update --init --recursive
# 3. 以项目三为例：独立虚拟环境 + 依赖 + 运行
cd works/03-综合成本与经营决策分析平台/cost_decision_platform
python -m venv .venv
.venv\Scripts\activate          # Windows；macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python main.py
提示：项目 04 的 fetch_data.py 需联网采集美的集团财报；项目 05 已内置数据快照，可 python run_all.py --skip-fetch 离线复现。遇到报错先翻手册第 8 章·排障总表。
