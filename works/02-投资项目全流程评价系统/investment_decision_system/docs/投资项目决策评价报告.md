## 二、评价方法与判据说明

### 2.1 净现值法（NPV）
计算式：`NPV = -I₀ + Σ(t=1..n) CFₜ / (1 + r)ᵗ`

其中 I₀ 为初始投资，CFₜ 为第 t 期净现金流，r 为折现率（资本成本）。
**判据**：NPV > 0 → 项目创造价值，方案可行；NPV ≤ 0 → 方案不可行。
独立项目决策中，NPV 是唯一理论上无缺陷的判据，也是互斥项目优选的首选准则。

### 2.2 内含报酬率法（IRR）
计算式：求解 r 使 `NPV(r) = 0`，该 r 即为 IRR。

本系统采用「网格扫描 + Brent 精解」的数值策略：先在 (-99%, 500%] 区间上
以 2000 点网格扫描 NPV 的符号变化区间，再对每个变号区间用 Brent 法精确定位，
**可同时捕获全部实根**，从而识别多重 IRR 异常情形。

**判据**：IRR > 资本成本 → 方案可行。
**局限**：非常规现金流（多次符号变化）可能导致 IRR 多解甚至无解，
此时 IRR 指标失效，必须以 NPV 为准，并辅以 MIRR（修正内部报酬率）。

### 2.3 年金净流量法（ANCF / 等额年金 EAA）
计算式：`ANCF = NPV / PVIFA(r, n) = NPV × r / [1 - (1 + r)^(-n)]`

**用途**：解决 **寿命期不同的互斥项目** 无法直接比较 NPV 的问题。
该方法把项目总 NPV 折算为「每年等额创造的价值」，使不同寿命的方案
在统一口径下可比。**判据**：ANCF 越大方案越优；ANCF > 0 项目可行。

### 2.4 盈利能力指数与资本限额下的项目分配
计算式：`PI = (NPV + I₀) / I₀`，表示单位投资额创造的现值。

资本限额下求解最优投资组合的三种方法：

1. **排序法**：按 PI 降序贪心装入。速度快，但隐含「资金可任意分割」假设，
   当资本额度不可分割时会因额度碎片化而错过全局最优解；
2. **组合法**：DFS 穷举全部可行组合（配合可行性剪枝与最优性剪枝），
   **保证全局最优**，是本系统的推荐方法；
3. **背包法**：把额度整数化后用 0-1 动态规划求解，复杂度 O(n × Budget)，
   适用于项目数很多、穷举不可行的场景，用于交叉验证组合法结果。

### 2.5 投资决策敏感性分析
分析折现率、初始投资、年现金流、项目寿命四项因素变动对 NPV 的影响：

* **单因素敏感性**：折现率按 **绝对百分点 ±5pp** 扰动，初始投资与年现金流
  按 **相对比例 ±20%** 扰动，寿命按 ±1 年扰动（不同因素口径不同，需标注清楚）；
* **临界点（盈亏平衡）分析**：求解使 NPV = 0 的临界折现率（数值上等于 IRR）、
  初始投资上限、年现金流下限，并换算为「可承受的最大不利变动幅度」；
* **安全边际**：`安全边际 = IRR − 资本成本`，用于量化抗风险能力；
* **双因素联动**：折现率 × 年现金流 二维矩阵，识别可行区与不可行区的分界线。

**tornado 图（旋风图）** 按各因素引起的 NPV 波动幅度降序排列，
条形越长说明该因素越关键；若不利方向的条形越过 NPV = 0 临界线，
则该因素一旦不利变动将直接导致项目失效，属 **致命敏感因素**。

### 2.6 AI 辅助功能
> **关于「AI 生成」的口径说明**：本系统的「AI 生成数据」指 **用行业知识构建参数区间，
> 再由程序在区间内约束采样**，而非由大模型逐条编造现金流数字；「AI 生成建议」指
> **规则引擎产出结论 + 大模型可选润色**。这是刻意的工程取舍，理由见下。

**（1）AI 生成测试数据**：采用「行业原型约束 + 参数化生成」策略，
基于 6 个行业的真实资本投资特征（新能源、半导体、生物医药、消费零售、
公用事业、数字软件）构建参数区间，再按 steady / growth / jcurve / cycle
四种现金流形态生成项目数据，覆盖不同规模（700~9000 万元）、
不同寿命（5~15 年）、不同风险等级。使用固定随机种子，**结果完全可复现**；
该策略避免了直接由大模型自由生成数字所导致的数量级失真与不可复现问题。

**（2）AI 生成决策建议**：采用「规则引擎 + 可选大模型润色」双通道架构。
规则引擎基于 8 类风险规则（安全边际、折现率冲击、投资超支容错、
现金流下滑容错、回收期占比、多重 IRR、现金流波动率、资本集中度）
自动生成带具体数字的结论、风险提示与建议动作，**离线可用、零幻觉、可追溯**；
若配置了大模型 API（`IDS_LLM_API_KEY`），则把已算好的结构化指标作为上下文
交给模型润色表达，并强制约束「不得修改任何数字」。
